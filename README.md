## Run locally

```bash
npm install
npm run dev
```

## Demo

Click **Try as Admin** or **Try as Client** on the login screen for instant one-click access — no credentials required.

## What's included

- React + Vite app
- Multi-tenant demo experience
- Dashboard, incidents, training, actions, inspections, documents, reports tabs
- Supabase client scaffold
